# Personal Gemini Journal

Personal Gemini Journal is an intelligent, private reflective journal powered by Gemini and Google Cloud.

## Features

- Daily mood tracking
- Personal journal entries
- AI-guided Socratic prompts using Gemini
- Secure authentication
- Firestore database integration
- Private and secure user data

## Technologies Used

- Google Gemini AI
- Firebase Authentication
- Cloud Firestore
- TypeScript
- Vite

## Security

Firestore security rules are included in the `firestore.rules` file to protect user data and ensure authorized access.

## Setup

1. Clone the repository
2. Install dependencies
3. Configure environment variables
4. Run the application

## Project Purpose

This project was created as part of the Google Gen AI Academy APAC program.
